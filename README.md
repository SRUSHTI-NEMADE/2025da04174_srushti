# ML Assignment 2 — Breast Cancer Classification

## a. Problem Statement
Build, evaluate, and deploy multiple classification models that predict whether a
breast tumor is **malignant (0)** or **benign (1)** based on measurements taken from
a digitized image of a fine needle aspirate (FNA) of a breast mass. This is a
**binary classification** problem, and the goal is to compare how different
classical ML algorithms perform on the same dataset, then expose the models
through an interactive Streamlit web app.

## b. Dataset Description
- **Name:** Breast Cancer Wisconsin (Diagnostic) Data Set
- **Source:** UCI Machine Learning Repository (also bundled with scikit-learn as
  `sklearn.datasets.load_breast_cancer`) — https://archive.ics.uci.edu/dataset/17/breast+cancer+wisconsin+diagnostic
- **Instances:** 569 (meets the ≥500 requirement)
- **Features:** 30 numeric features (meets the ≥12 requirement) — mean, standard
  error, and "worst" values of 10 real-valued measurements computed for each cell
  nucleus (radius, texture, perimeter, area, smoothness, compactness, concavity,
  concave points, symmetry, fractal dimension).
- **Target:** Binary — `0 = malignant`, `1 = benign` (class balance: 212 malignant,
  357 benign)
- **Train/Test split:** 80% / 20%, stratified on the target, `random_state=42`

> **Note:** `test_data.csv` in this repo is the held-out 20% test split (114 rows)
> used both for offline evaluation and as the file to upload to the Streamlit app.

### Observations

| ML Model Name | Observation about model performance |
|---|---|
| Logistic Regression | Top performer on nearly every metric. The classes are fairly linearly separable in the scaled feature space, so a simple linear decision boundary works very well and the model doesn't overfit despite having 30 features. |
| Decision Tree | Weakest model overall (lowest accuracy, AUC, and MCC). A single unpruned tree overfits the training split and is sensitive to small variations in feature values, hurting generalization on the test set. |
| kNN | Solid performance once features are standardized (distance-based, so scaling matters a lot). Slightly behind LR/SVM because local neighborhoods can be noisy near the decision boundary. |
| Naive Bayes | Decent AUC (ranks probabilities well) but lower accuracy/MCC than the top models — the Gaussian independence assumption between the 30 correlated features (e.g., radius/perimeter/area) is violated, which hurts hard classification even though ranking stays good. |
| Random Forest (Ensemble) | Improves substantially over a single Decision Tree by averaging many trees, reducing variance/overfitting. Matches kNN on most metrics and has the second-highest AUC, showing ensembling is effective on this dataset. |
| **Overall Winner for your dataset?** | **Logistic Regression** (tied with SVM on Accuracy/Precision/Recall/F1/MCC, but marginally higher AUC). This suggests the dataset is close to linearly separable, so the simpler, more interpretable linear model is preferable to the more complex, harder-to-interpret SVM/ensemble models. |
